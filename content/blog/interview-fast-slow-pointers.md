The fast/slow pointer technique is one of the most elegant ideas in linked list algorithms. Also known as Floyd's Tortoise and Hare algorithm, the core insight is deceptively simple: if you send two pointers through a sequence at different speeds, the faster one will either reach the end or lap the slower one inside a cycle. From this observation, a surprisingly wide range of problems become solvable with O(1) extra space.

## The Core Pattern

```python
slow = head
fast = head

while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
    # At this point, check your condition
```

The fast pointer advances two steps for every one step of the slow pointer. This simple differential is what makes the technique work.

## Problem 1: Detect a Cycle in a Linked List

**LeetCode 141.** Given the head of a linked list, determine if it has a cycle.

```python
def hasCycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            return True
    return False
```

**Why this works:** If a cycle exists, the fast pointer will enter the cycle and keep looping. The slow pointer will eventually enter the cycle too. Once both are in the cycle, the fast pointer gains on the slow pointer by one node per step — so it will inevitably catch up and they will meet.

If no cycle exists, the fast pointer reaches the end (None) and the while loop terminates.

**Time:** O(n). **Space:** O(1).

## Problem 2: Find the Cycle Start (Entry Point)

**LeetCode 142.** If a cycle exists, return the node where the cycle begins.

This requires a mathematical insight. Let F = distance from head to cycle start, C = cycle length, k = distance from cycle start to meeting point (within cycle). When slow and fast meet, slow has traveled F + k steps. Fast has traveled 2(F + k) steps. The extra distance implies F = nC - k, meaning advancing F more steps from the meeting point brings you to the cycle start — which is the same as advancing F steps from head.

```python
def detectCycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            pointer = head
            while pointer != slow:
                pointer = pointer.next
                slow = slow.next
            return pointer
    return None
```

Pattern to remember: after the meeting, reset one pointer to head and advance both one step at a time until they meet again. That meeting point is the cycle start.

## Problem 3: Find the Middle of a Linked List

**LeetCode 876.** Return the middle node of a linked list.

When fast reaches the end, slow is at the middle.

```python
def middleNode(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    return slow
```

For odd-length lists, slow lands on the exact middle. For even-length lists (6 nodes), slow lands on the second of the two middle nodes. If you need the first middle node, adjust the loop condition to `while fast.next and fast.next.next`.

**Application:** Merge sort on linked lists uses this to split the list in half recursively.

## Problem 4: Happy Number

**LeetCode 202.** A number is "happy" if repeatedly replacing it with the sum of squares of its digits eventually reaches 1. Detect if a number is happy.

This is a cycle detection problem in disguise — if the number is not happy, it enters an infinite loop cycling through non-1 values.

```python
def isHappy(n):
    def get_next(num):
        total = 0
        while num > 0:
            digit = num % 10
            total += digit * digit
            num //= 10
        return total

    slow = n
    fast = get_next(n)

    while fast != 1 and slow != fast:
        slow = get_next(slow)
        fast = get_next(get_next(fast))

    return fast == 1
```

The sequence of values generated by the "sum of squares of digits" operation is like a linked list where each value points to the next. Fast/slow pointers detect whether the sequence cycles back to a non-1 value or terminates at 1.

## Problem 5: Reorder List

**LeetCode 143.** Given a linked list L0 → L1 → ... → Ln, reorder it to L0 → Ln → L1 → Ln-1 → L2 → Ln-2.

This problem combines three techniques: find the middle (fast/slow), reverse the second half, and merge the two halves alternately.

```python
def reorderList(head):
    # Step 1: Find middle
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next

    # Step 2: Reverse second half
    prev, curr = None, slow.next
    slow.next = None  # Cut the list
    while curr:
        nxt = curr.next
        curr.next = prev
        prev = curr
        curr = nxt
    second = prev

    # Step 3: Merge alternately
    first = head
    while second:
        tmp1, tmp2 = first.next, second.next
        first.next = second
        second.next = tmp1
        first = tmp1
        second = tmp2
```

## The Pattern Recognition

Fast/slow pointers apply whenever:
1. You need to detect a cycle in a sequence (linked list or number sequence)
2. You need to find a structural midpoint
3. You need to find the cycle entry point after detection

The O(1) space constraint is what makes this technique valuable. Hash set solutions exist for all these problems but use O(n) space. Fast/slow pointers are the preferred interview solution precisely because they require understanding the underlying structure rather than storing visited states.
