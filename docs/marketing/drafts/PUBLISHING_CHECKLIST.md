## Content Quality Checklist

Before each post, verify:

### Copy

- [ ] No typos or grammar errors
- [ ] Line breaks preserved correctly
- [ ] Hashtags relevant and active
- [ ] Character count within limits

### Engagement

- [ ] Clear hook in first 2 lines
- [ ] Question or CTA at end
- [ ] Engagement prompt prepared as first comment

### Visual (if applicable)

- [ ] Image is high-quality (1200x628 LinkedIn, 1200x675 Twitter)
- [ ] Text is readable
- [ ] Brand colors used
- [ ] Alt text added for accessibility

## Emergency Procedures

### Post Not Performing

Wait 24 hours before judging. If still low:
1. Delete and repost at different time
2. Add image if text-only
3. Tag relevant people/accounts

### Negative Engagement

1. Respond professionally
2. Don't delete unless truly offensive
3. Use as learning opportunity
4. DM critics privately if constructive

### Platform Issues

1. Have backup scheduling tool ready
2. Save all content locally
3. Screenshot scheduled posts
